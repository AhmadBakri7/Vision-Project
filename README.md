This project focuses on leveraging deep learning techniques to solve a computer vision problem by designing, training, and evaluating convolutional neural networks (CNNs). The first phase involves building and training a custom CNN by defining its architecture, optimizing hyperparameters, and assessing its performance. Next, data augmentation techniques are applied to enhance the model's generalization ability, followed by retraining and evaluating its impact. In the third phase, a well-known published CNN architecture is selected and trained using the augmented dataset to compare its performance with the custom model. Finally, transfer learning is implemented by fine-tuning a pre-trained CNN model on the given dataset to further improve accuracy.
